# Ոսկեվան AI

## Ֆայլերը
- `index.html` — կայքի տեսքը և չաթը
- `netlify/functions/tutor.mjs` — անվտանգ սերվերային ֆունկցիան, որը կանչում է OpenAI API-ն
- `netlify.toml` — Netlify-ի կարգավորումները

## Netlify կարգավորում
1. Վերբեռնիր այս ZIP-ի պարունակությունը GitHub repository-ի հիմնական պանակում՝ պահպանելով պանակների կառուցվածքը։
2. Netlify-ում բացիր Site configuration → Environment variables։
3. Ավելացրու `OPENAI_API_KEY` անունով գաղտնի փոփոխական, իսկ Value դաշտում՝ API key-ը։
4. Պահպանիր փոփոխությունը և արա նոր deploy։

API key-ը երբեք մի գրիր `index.html`-ում կամ GitHub-ի հանրային ֆայլում։ API-ի օգտագործումը կարող է վճարովի լինել․ հաշվի և վճարումների կարգավորումը պետք է անի ծնողը կամ դպրոցի պատասխանատու չափահասը։

## Նշում
Կոդը նախատեսված է Netlify Functions-ի և OpenAI Responses API-ի համար։ Իրական աշխատելը կախված է Netlify-ի ճիշտ deploy-ից, գաղտնի բանալու վավեր լինելուց, հաշվի API հասանելիությունից և սահմանաչափերից։
